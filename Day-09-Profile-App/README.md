🚀 Day 9: Profile App (Data Entry System) 

📌 Project Overview: This is a desktop application developed using Java Swing and JDBC (Java Database Connectivity). It functions as a data entry form that allows users to input personal details and saves them permanently into a MySQL database.

The application includes features such as:
 • Data Collection: Captures user Name, Mobile Number, and Qualification via text fields.
 • Gender Selection: Implements JRadioButton and ButtonGroup to select gender (Male/Female).
 • Database Integration: Successfully connects to a MySQL server to store user records persistently (as shown in the demo, data is verifiable via SQL queries).
 • Success Feedback: A JOptionPane dialog confirms when data is "Saved Successfully."

🛠️ Tech Stack Used:
 • Language: Java (Core Logic)
 • GUI Framework: Java Swing (JFrame, JLabel, JTextField, JRadioButton)
 • Database: MySQL (Backend storage)
 • Connectivity: JDBC (To bridge Java and MySQL)

💡 Key Learnings:
 Through this project, I learned how to: 
 • Establish a connection between a Java application and a MySQL database using JDBC.
 • Create SQL queries inside Java to Insert data dynamically.
 • Manage Radio Buttons to ensure only one option is selected at a time.
 • Validate and transfer GUI data to a backend system.
