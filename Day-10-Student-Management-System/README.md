🚀 Day 10: Student Management System 

📌 Project Overview:
This is a Java Swing–based desktop application designed to manage student records efficiently.
The system allows users to add, view, update, and manage student details through a simple and interactive interface.

✨ Key Features:
 • Add new student records with proper input validation
 • Display student details in an organized format
 • Update and manage existing student information
 • User-friendly GUI for smooth interaction
 • Confirmation dialogs to avoid accidental actions

🛠️ Tech Stack Used:
 • Language: Java
 • GUI Framework: Java Swing (JFrame, JTextField, JButton, JTable)
 • Dialogs: JOptionPane
 • Core Concepts: OOP, Event Handling, Data Validation

💡 Key Learnings:
 Through this project, I strengthened my understanding of:
 • Object-Oriented Programming concepts
 • Building complete desktop applications using Java Swing
 • Managing user input and application flow
 • Structuring real-world mini projects
