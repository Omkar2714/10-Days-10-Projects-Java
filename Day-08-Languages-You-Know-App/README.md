Day 8: Languages You Know App (with Database)

📌 Project Overview: This is a full-stack desktop application developed using Java Swing and JDBC. While my Day 7 project handled single choices (Radio Buttons), this project focuses on multiple selections using Checkboxes, processing them into a single format, and storing them in MySQL.

The application includes features such as: 
• Multiple Skill Selection: Users can select multiple programming languages (e.g., Java, Python, JavaScript) using JCheckBox components. 
• Data Formatting: The app logically validates selections and concatenates them (e.g., "Java, JavaScript") before sending data to the backend. 
• Database Integration: Securely connects to MySQL to permanently save the user's Name and Skillset. 
• Input Validation: Ensures that the user enters a name and selects at least one skill before submitting.

🛠️ Tech Stack Used: 
• Language: Java (Core Logic) 
• GUI Framework: Java Swing (JCheckBox, JTextField, JButton) 
• Database: MySQL Server 
• Connectivity: JDBC (Java Database Connectivity) API

💡 Key Learnings: 
Through this project, I learned how to: 
• Handle Boolean Inputs from multiple checkboxes. 
• Perform String Manipulation to format multiple user choices for database storage. 
• Write complex SQL INSERT queries dynamically from Java.
