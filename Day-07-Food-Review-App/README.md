Day 7: Food Review App (with Database)

📌 Project Overview: This is a full-stack desktop application developed using Java Swing and JDBC. Unlike my previous projects that lost data after closing, this app permanently stores user reviews and ratings in a MySQL Database.

The application includes features such as: 
• Database Integration: Seamlessly connects to a MySQL server to save Food Name, Rating, and Review text permanently. 
• Rating System: Implemented JRadioButton groups to allow users to select a rating from 1 to 5. 
• Input Validation: Prevents invalid entries by alerting the user ("Food Name cannot be empty") if fields are missing. 
• Data Persistence: Verified the data storage by running SQL queries (select * from person;) in the terminal.

🛠️ Tech Stack Used: 
• Language: Java (Core Logic) 
• GUI Framework: Java Swing (JRadioButton, JTextArea, JButton) 
• Database: MySQL Server 
• Connectivity: JDBC (Java Database Connectivity) API

💡 Key Learnings: 
Through this project, I learned how to: 
• Establish a connection between a Java application and a MySQL Database using JDBC. 
• Execute SQL queries (INSERT) directly from Java code. 
• Use ButtonGroup to manage radio button selections effectively.
